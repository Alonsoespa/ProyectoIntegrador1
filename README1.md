# Sales Management System

A desktop sales management application developed in Java using Swing for the graphical user interface and MySQL for data storage.

This project was developed as an academic project to practice software development and database integration.

## Features

- **Sales Management:** Register and manage sales.
- **Product Management:** Manage product information.
- **Customer Management:** Manage customer information.
- **Sales Reports:** View sales reports.

## Technologies Used

- **Java:** Application development.
- **Java Swing:** Graphical user interface.
- **MySQL:** Relational database.

## Requirements

To run this application, you may need:

- Java Development Kit (JDK) compatible with the project.
- MySQL Server.
- The project dependencies and database configuration required by the application.

## Getting Started

1. Clone or download this repository.
2. Open the project in Apache NetBeans.
3. Configure the MySQL database connection according to your local environment.
4. Ensure that the required database and tables are available.
5. Build and run the application.

**Note:** Database setup and configuration depend on the implementation included in this project.
