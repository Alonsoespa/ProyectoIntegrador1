
# Sales Management System

A desktop application developed in Java to manage sales-related operations, customer information, and payments. The application uses Java Swing for its graphical user interface and MySQL for database integration.

This project was developed as part of my Software Development studies at Universidad Tecnológica de Aguascalientes.

## Features

- **Customer Management:** Manage customer information.
- **Customer Search:** Search and consult registered customers.
- **Sales Management:** Manage sales-related operations.
- **Payment Management:** Manage payment-related operations.
- **User Login:** Access the application through a login screen.
- **Main Menu:** Navigate between the application's main modules.

## Technologies Used

- **Java:** Application development.
- **Java Swing:** Graphical user interface.
- **MySQL:** Relational database.
- **Apache NetBeans:** Development environment.

## Requirements

- Java Development Kit (JDK) compatible with the project.
- MySQL Server.
- Apache NetBeans or another compatible Java IDE.
- The required database schema and connection configuration.

## Getting Started

1. Clone or download this repository.
2. Open the project in Apache NetBeans.
3. Configure the MySQL database connection.
4. Set up the required database and tables.
5. Build and run the application.

**Note:** Database configuration and setup depend on the implementation of the project. Do not publish database credentials or other sensitive information.
